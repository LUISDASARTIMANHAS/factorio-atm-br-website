
# Factorio ATM BR Website
rw
## Introdução

Este projeto consiste em um website para a comunidade brasileira de jogadores de Factorio, especificamente para o servidor "ATM BR". O website serve como um portal central para a comunidade, oferecendo uma variedade de ferramentas e recursos para melhorar a experiência de jogo.

## Objetivo

O objetivo principal deste projeto é fornecer uma plataforma centralizada e de fácil acesso para a comunidade "Factorio ATM BR", oferecendo ferramentas e recursos que facilitem a interação, o gerenciamento de mods e o acesso a informações relevantes sobre o servidor.

## Tecnologias Utilizadas

O website foi desenvolvido utilizando as seguintes tecnologias:

*   **Frontend:** HTML5, CSS3, JavaScript
*   **Bibliotecas:** Bootstrap 5.3.6, Popper.js 2.11.8
*   **Estrutura de Arquivos:** O projeto é organizado em diretórios modulares, separando as diferentes funcionalidades do site (chat, downloads, login, etc.).

## Funcionalidades

O website implementa as seguintes funcionalidades:

*   **Chat:** Uma sala de chat para a comunicação em tempo real entre os jogadores.
*   **Downloads:** Uma seção para o download de mods e outros arquivos relacionados ao jogo.
*   **Login de Usuário:** Um sistema de autenticação para o acesso a áreas restritas do site.
*   **Mod Downloader:** Uma ferramenta para o gerenciamento e download de mods do Factorio.
*   **Mod Toolkit:** Um conjunto de ferramentas para a configuração e gerenciamento de mods.
*   **Sistema de Upload:** Uma funcionalidade para o envio de arquivos para o servidor.

## Proposta

A proposta do projeto é criar um ambiente virtual que transcenda o jogo, oferecendo um espaço para a comunidade "Factorio ATM BR" se conectar, colaborar e compartilhar informações. O website visa aprimorar a experiência de jogo, fornecendo ferramentas que automatizam e simplificam tarefas comuns, como a instalação e atualização de mods. Além disso, o site serve como um repositório de conhecimento, onde os jogadores podem encontrar informações sobre o servidor, guias de jogo e outros recursos úteis.
